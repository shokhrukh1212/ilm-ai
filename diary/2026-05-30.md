## Problems encountered — Phase 4

1. **Explainer prompt has per-answer placeholders** — The blueprint Quiz Explainer prompt embeds `{lang}/{prompt}/{correct}/{user_answer}`, so it can't be a static system prompt (literal braces would leak).

2. **Quiz generation has no search query** — Unlike chat, there's no user query to retrieve against, so the generator needs representative source coverage.

## Solutions — Phase 4

1. Kept the exact blueprint text as a template formatted per request and delivered as the run input (same pattern as the generator), with the agent a reusable singleton typed to `Explanation`.

2. Even-sample child chunks across the material by stored order (stride = ceil(total/cap)), labeling each by real chunk id so questions cite real sources.
